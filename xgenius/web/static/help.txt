1. 🔝 ВЕРХНЕЕ МЕНЮ (МАССОВОЕ УПРАВЛЕНИЕ)
══════════════════════════════════════════════════

🔒 [Close All]
   Экстренное выключение. Мгновенно закрывает ВСЕ открытые браузеры и останавливает все процессы.

🔒 [Close Selected]
   Закрывает браузеры только у тех аккаунтов, где вы поставили галочку (слева в таблице).

✔️ [Select to Start]
   Массовый вход. Отметьте галочками нужные аккаунты, нажмите кнопку, и бот по очереди (раз в 15 сек)
   откроет браузеры и войдет в аккаунты.

📝 [Bulk Edit]
   Массовое изменение данных. Позволяет сменить Прокси или Группу сразу для кучи выделенных аккаунтов.

📝 [Mass MSG Edit]
   Массовая настройка задач. Вы настраиваете текст рассылки и задержки один раз, а применяются они
   ко всем выделенным аккаунтам сразу.

📤 [Export Chats] - НОВАЯ ФУНКЦИЯ
   Экспорт информации о чатах. Выберите аккаунты и экспортируйте список всех их чатов в текстовый файл.

🚀 [Mailing Selected]
   Запускает рассылку только на отмеченных галочкой аккаунтах (они должны быть уже залогинены).

🚀 [Mailing for Ready]
   Умный запуск. Бот сам найдет все аккаунты, которые 'готовы' (Готов = Статус Active + Есть группы + Есть текст)
   и запустит на них работу.

📊 [History]
   Глобальная статистика. Показывает таблицу успехов за выбранный период (сообщения, ретвиты, комменты).

🖥 [Monitor]
   Живой лог. Окно, где пишется каждое действие бота в реальном времени.

2. 📋 ТАБЛИЦА (УПРАВЛЕНИЕ ОДНИМ АККАУНТОМ)
══════════════════════════════════════════════════

🔲 [Чекбокс] — Выделить аккаунт для массовых действий.

🔑 [Login]
   Открывает Chrome, загружает куки и входит в профиль. Ждите зеленый статус 'Active'.

👀 [View] (Глаз)
   Найти потерянное окно. Если браузеров много, нажмите, чтобы вывести окно этого аккаунта на передний план.

🔍 [Parse] (Парсинг)
   Сканирует личные сообщения (DM). Бот листает диалоги, находит групповые чаты и сохраняет их в базу.
   Нужно делать 1 раз перед первой рассылкой.

📨 [Mailing] (Рассылка)
   Запускает главный рабочий цикл: Отправка сообщений -> Ретвиты -> Отдых -> Повтор.

✏️ [Edit]
   Редактировать Логин, Пароль, Прокси или Группу аккаунта.

⚙️ [Settings]
   Настройка рассылки для этого аккаунта:
   - Msg cycle: Сколько сообщений слать за раз.
   - Rest time: Время отдыха (в минутах).
   - Mailing Messages: Тексты сообщений (поддерживает рандомизацию).

💬 [Comm] (Комментарии)
   Настройка авто-комментинга. Укажите файлы со списком юзеров и текстами.
   Бот будет комментировать их во время паузы (Rest time).

⏸ [S] (Stop) — Поставить аккаунт на паузу.
▶️ [R] (Resume) — Снять с паузы.
📊 [Stat] — Показать статистику этого аккаунта за сегодня (24ч).

❌ [Close]
   Закрывает браузер и СБРАСЫВАЕТ ОШИБКУ (очищает красный статус).

🗑 [Delete] — Удалить аккаунт из программы навсегда.

3. ⚙️ ЛОГИКА РАБОТЫ (КАК ЭТО РАБОТАЕТ)
══════════════════════════════════════════════════

🔄 ЦИКЛ РАССЫЛКИ (Mailing):
   1. Бот заходит в найденную группу.
   2. Пишет текст (уникализирует буквы и смайлы).
   3. Если включено, отправляет GIF.
   4. Отправляет N сообщений (настройка Msg cycle).
   5. Делает ретвиты (если настроено).
   6. Уходит на 'Отдых' (Rest time).

💬 КОММЕНТИНГ (Smart Comments):
   Работает ТОЛЬКО во время 'Отдыха' между рассылками.
   1. Бот берет юзера из вашего файла (Targets).
   2. Идет к нему в профиль.
   3. Находит закрепленный или последний твит.
   4. Пишет коммент (из файла) + прикрепляет фото (из папки).

4. 🚦 СТАТУСЫ И ОШИБКИ (НОВЫЕ!)
══════════════════════════════════════════════════

🟢 Active — Все отлично, аккаунт готов.
🔵 Mailing — Идет работа.
🟠 Paused — Аккаунт на ручной паузе.
🟣 NEED RELOGIN — Аккаунт разлогинился, требуется перелогин.
🔴 SUSPENDED — Аккаунт забанен Твиттером навсегда.
🔴 LOCKED / CAPTCHA — Твиттер просит подтвердить, что вы человек. Нужно зайти руками.
🔴 DM LIMIT 4H — Лимит на отправку сообщений. Бот сам поставил паузу на 4 часа, потом продолжит.
